# Holistic HTTP workload matrix, 2026-08-12

This run expands the original plaintext comparison into four independently
validated workloads. All servers were pinned to quiet physical CPU 12 (sibling
13 was also effectively idle); `oha` was pinned to CPUs 16-31. Each number is
the median of three 10-second measurements after a 3-second warm-up at 64
connections over HTTP/1.1 keep-alive.

| Scenario | Abla req/s | Go req/s | Rust req/s | Abla vs Go | Abla vs Rust |
| --- | ---: | ---: | ---: | ---: | ---: |
| Plaintext | 220,459 | 168,156 | 282,622 | 131.1% | 78.0% |
| Path + query parameters | 175,919 | 156,926 | 246,498 | 112.1% | 71.4% |
| Bearer middleware + request locals | 65,355 | 161,106 | 252,359 | 40.6% | 25.9% |
| 16 KiB binary echo | 41,331 | 103,304 | 157,154 | 40.0% | 26.3% |

| Scenario | Abla p50 | Abla p99 | Go p50 | Go p99 | Rust p50 | Rust p99 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Plaintext | 0.243 ms | 0.491 ms | 0.379 ms | 0.790 ms | 0.230 ms | 0.241 ms |
| Path + query parameters | 0.331 ms | 0.667 ms | 0.406 ms | 0.849 ms | 0.262 ms | 0.273 ms |
| Bearer middleware + request locals | 0.448 ms | 0.921 ms | 0.396 ms | 0.827 ms | 0.256 ms | 0.270 ms |
| 16 KiB binary echo | 1.261 ms | 3.584 ms | 0.621 ms | 1.228 ms | 0.405 ms | 0.429 ms |

The context scenario performs real bearer-header validation, creates a
structured user, stores the principal and user in directional request locals,
and reads them in the downstream handler. The Abla Web API is immutable from
the caller's perspective: only the context passed to `next` observes a new
local. An O(1) linked local stack measured 65,355 requests/second. A rejected
compact-node experiment used four typed arrays instead; despite narrower
entries, the extra array containers and copying reduced the Abla median to
60,451 requests/second, so it was reverted.

The body scenario uncovered and fixed two event-server correctness bugs before
the final measurement: a complete `Content-Length` frame had included request
headers in the parsed body, and request bytes accumulated across multiple
socket reads could retain a reset request-region allocation. Regression tests now cover both
the exact body slice and an 8 KiB body deliberately delivered across reads.

The result gives a more useful optimization order than plaintext alone:

1. reduce closure/dynamic-dispatch and allocation cost in the general WebApp
   middleware chain;
2. specialize the common one-or-two-local case without changing directional
   semantics; and
3. replace repeated 4 KiB string concatenation for bodies with a bounded
   connection input buffer or chunk list, then render large responses without
   another full-body copy.

Machine: Intel Core i9-13900K; Go 1.25.1; Rust 1.95.0; oha 1.10.0. The raw JSON
is intentionally ignored because it includes large per-sample histograms; the
committed summary contains the reproducible configuration and medians.
