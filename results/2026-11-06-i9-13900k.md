## Where Abla remains behind

There are three clear one-worker median gaps: JSON strings (24.1% behind Rust), 32 headers (14.9% behind Zig), and parameters (10.1% behind Zig, with overlapping repetition ranges and thus less certainty). Unicode JSON is about 0.5% behind Rust, which is parity at this measurement’s resolution. Do not infer five significant gaps from this dataset. Three samples are retained rather than selecting favorable repetitions.

Across all 21 one-worker scenarios, Abla has the highest median in 17, with Unicode effectively tied. Plaintext reaches 333,399 req/s versus Go 165,731, Rust 255,338 and Zig 276,928. These are proposals, not implemented wins. Attribution names come from the frozen compiler’s output and matching sources. The event path already parses the head once and retains the request; “remove a second full parse” would be a stale proposal. `HttpRequest.header` already searches backward and stops at the last duplicate, so the candidate must go beyond that existing optimization.

Diagnostic method: existing `diagnostics/profile_json.py`, five selected scenarios, user cycles/instructions counters and cycle samples; zero lost samples in the inspected reports. Its Abla/Zig diagnostics run on CPU 2 with clients 16–31, and Zig uses one event plus one handler worker, while the primary default matrix uses CPU 0 and Zig one plus two. Therefore diagnostic cross-language counts are not a matched primary throughput comparison, and no Zig diagnostic RPS is substituted for the table. Rust is the primary JSON-strings winner but was not profiled; the JSON cause is Abla’s measured self cost, not an inferred Rust implementation. Raw evidence: `build/current-lab/profiles/summary.json`, `*-abla.txt`, `*.stat`, `*.perf`.

The workload/API differences already present in the harness are retained: parameters-16 uses positional path/query access in Abla and Zig, named access in Go, and mixed access in Rust. JSON cases use a fixed compact field order; Abla uses its canonical-order streaming reader/encoder, while peers use typed schema decoders/serializers. These results describe those programs, not all JSON or routing APIs. The raw configuration records these differences.
